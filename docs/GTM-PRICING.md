# Return Saver — 销售主张与定价

## 一、打动客户的三个点（以及怎么证明）

销售话术必须和 QBR 口径一致，否则第一个季度复盘就会崩。每条主张配一个可验证口径和证明方式。

### 1. 退货率降低 80%

**口径**：**可挽回退货（addressable returns）中的挽留率 80%**，不是全量退货率下降 80%。

分母排除三类本来就不该挽留的请求：到货破损/错发、明确质量缺陷、超窗口不符合规则。这三类在 DTC 场景通常占退货总量的 30–45%。

| 口径 | 数值 | 用途 |
|---|---|---|
| Addressable deflection rate | 目标 80% | 对外主张、合同 SLA |
| Overall deflection rate | 折算 20–30% | QBR、财务模型 |

**证明方式**：强制 10% holdout 对照组（`RS_HOLDOUT_PCT=10`），只比增量；结算窗口 **60 天**，二次退货回冲。代码里 `/api/metrics` 同时上报两个口径，就是为了防止销售和交付各说各话。

> 如果客户要的是「全量退货率下降 80%」，直说做不到——没有任何对话式产品能做到，承诺了就是埋雷。

### 2. 客户满意度提升 30%

**口径**：售后触点 CSAT 相对基线的提升。

驱动来自三件事，而且都不是「挽留」带来的：
- **小额秒退**：情绪激烈 + ≤$50 立即退款，不审核、不推诿（传统人工平均 2–5 天）
- **使用类问题直接解决**：手册 / 视频 / 1v1 指导，用户要的本来就不是退钱
- **大额人工介入给死时效**：2 小时 SLA + 退货窗口冻结，比「已转接，请等待」强一个量级

**证明方式**：每次会话结束推 CSAT（`POST /api/csat`），按 scenario 分层看。重点盯 `not_eligible` 这一档——婉拒场景的 CSAT 才是产品有没有伤体验的真实体温计。

### 3. 营收增长 40%

**口径**：**售后相关可挽回营收**的增长，不是公司总营收增长 40%。拆成三块，每块单独可测：

| 来源 | 机制 | 占比（经验估算） |
|---|---|---|
| 挽回订单 | 未发生的退款 | ~60% |
| 换货加购 | 换码/换款时的连带购买 | ~15% |
| 回头复购 | `experience_hook` 补偿 credit 的 90 天内核销 | ~25% |

**证明方式**：三块分别埋点，credit 核销走独立归因。对外讲「40%」时必须带上「售后相关」四个字。

## 二、定价：三档

> 档位在代码里是 `rs_tenant.plan`（`starter` / `pro` / `advanced`），每档带一个
> `cost_budget_usd` 默认值（0.02 / 0.05 / 0.15，平台天花板 0.30）。见
> `db/migrations/001_multitenant_config.sql`。

单位经济基线：AOV $100、毛利率 60% → **单次成功挽留净值约 $60**（保住毛利 $60 + 省下逆向物流 $15 − 让利成本 $15）。

实测 LLM 成本（路由后，mock token 估算）：**$0.0014 / 次对话**，约为 case 预算 $0.15 的 **0.9%**。生产按真实 token 保守放大到 $0.01–0.03 / 次对话仍远低于预算。

> 真正的 COGS 大头不是 LLM，是**人工介入工单**（每单约 $3–5 人力）。所以三档都要盯 escalation rate，Advanced 档直接写进合同。

| | **Starter** | **Pro** | **Advanced** |
|---|---|---|---|
| 适用 | 月退货请求 < 300 | 300 – 3,000 | > 3,000 或 GMV > $5M |
| 计费 | **纯按单量** | **月套餐** | **月套餐 + 挽留收益分成** |
| 价格 | $0 平台费<br>**$9 / 次成功挽留** | **$699 / 月**<br>含 150 次，超出 $6 / 次 | **$2,999 / 月**<br>+ 挽回净值 **8%** 分成 |
| 折合单价 | $9.00 | ~$4.66 | ~$8.13（含分成） |
| 客户 ROI | ~6.7x | ~11x | ~7.4x |
| 含 | 标准规则引擎、四层护栏、看板 | \+ 自定义售后规则、A/B、holdout 报告 | \+ 私有化规则引擎、品牌口吻微调、专属 CSM、escalation SLA 合同化 |

**三档为什么这么设计**

- **Starter 按单量、零平台费**：小商家现金流敏感，任何月费都是转化阻力。按结果付费是最好卖的形态，也天然筛掉「装了不用」的客户。代价是单价必须高（$9），覆盖低频客户的固定成本。
- **Pro 月套餐**：中型客户要的是**可预测支出**和走采购流程的发票。套餐折合单价比 Starter 低 48%，升级动机内建在价目表里。超出部分按 $6 续费，避免超量惩罚劝退。
- **Advanced 月套餐 + 分成**：大客户既要总成本可控（底座费），又愿意为上不封顶的效果付钱（分成）。8% 分成把我们和客户的利益绑在同一个数上——**挽回净值**，而这个数是扣掉让利成本的，所以我们没有动机去猛发券刷量。

**毛利**：Starter/Pro 档在 $6–9 单价下，LLM + 基础设施 COGS < $0.15/save，毛利率 > 95%；Advanced 档因含 CSM 与 SLA，目标毛利率 80–85%。

**价格护栏**：分成只按**净值**计算（已扣让利与 API 成本），不按 GMV。按 GMV 分成会激励我们把折扣做大，那是自毁产品。

## 三、异议应对

| 客户说 | 回应 |
|---|---|
| 「AI 会不会乱承诺退款？」 | 金额不由模型生成——模型的输出结构里根本没有金额字段。四层护栏 + 执行层独立复核，现场可以演示拦截。 |
| 「会不会为了留住订单把用户惹毛？」 | 最多谈 2 轮、全程一键退出、情绪超阈值强制停止挽留，这三条是代码级硬约束，不是 prompt 里的建议。CSAT 按场景分层上报。 |
| 「80% 听起来太假」 | 是 addressable 口径，分母排除破损/错发/超窗口。全量口径我们承诺 20–30%，合同按这个签。 |
| 「怎么证明是你们的功劳？」 | 强制 10% holdout 对照组，只报增量，60 天结算窗口。 |
| 「合规风险呢？」 | 符合规则的退货绝不拒绝、绝不加阻力（美欧消费者保护红线）；婉拒必须附规则原文，可审计。 |
